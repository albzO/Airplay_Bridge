# AirPlay Hub · Ely GPUI 界面

基于 [Ely GPUI Components](https://elygpui.com) 的桌面界面，接入 `airplay-desktop` 的真实服务：来源枚举与采集、接收端发现、串流会话、密码、音量、设置保存、诊断与日志、托盘和单实例。

## 运行

先按 [构建指南](../../docs/building.md) 生成 `dist/runtime`（原生后端与 DLL）。调试构建会在可执行文件旁找不到 `runtime/` 时回退到 `dist/runtime`。

```bash
cargo run
```

可执行文件名为 `airplay-bridge-gpui.exe`。桌面服务按这个名字把它当作预览版：使用独立的开机自启项，不与已安装的 AirPlay Hub 冲突。

配置默认读写 `%APPDATA%\AirPlay Hub`，与已安装版本共用。想用独立数据目录，在可执行文件旁放一个空的 `portable.flag`，数据会写到同目录的 `data/`。

`scripts/build-gpui.ps1` 仍然构建 `src-gpui`，还没有改为打包本目录。

## 代码结构

| 文件 | 职责 |
|---|---|
| `src/main.rs` | 入口、窗口选项、错误对话框 |
| `src/shell.rs` | 单实例信号、托盘、关闭到托盘与退出收尾 |
| `src/player.rs` | 播放器状态与操作：来源、接收端、会话、密码、音量、设置保存 |
| `src/view.rs` | 标题栏、播放页、密码输入、底部固定栏 |
| `src/settings_view.rs` | 常规、运行统计、技术详情、日志 |
| `src/panel.rs` | 分组卡片、数据行和网格常量 |
| `src/visibility.rs` | 窗口可见性：托盘、最小化、显示器熄灭，据此暂停和恢复空闲采集 |
| `src/lang.rs` | 界面语言：系统默认、保存的选择、`t` 与 `tf!` |

会话状态机、事件收件箱、诊断、音量解析和后台作业直接引用 `../src-gpui/src/` 下的同名文件（`session.rs`、`inbox.rs`、`diagnostics.rs`、`volume.rs`、`desktop_job.rs`）。这些文件不依赖 gpui，两套界面共用一份。删除 `src-gpui` 前需要先把它们移过来。

## 空闲时的采集

没有串流时，采集只为显示电平。窗口收进托盘、最小化或显示器熄灭后停止采集并释放音频设备；窗口恢复可见时自动重新开启，失败会每 2 秒重试，最多 3 次（显示器音频端点在亮屏后要过一会儿才出现）。

- 串流中不受影响；串流在后台结束时，如果窗口不可见就停掉采集。
- 用户自己关闭的采集不会被自动恢复。
- 不到 0.4 秒的最小化不会触发。

## 语言

界面支持中文和英文，文字集中在各视图里以 `t("中文", "English")` 成对书写，带参数的用 `tf!`。

- 默认跟随 Windows 显示语言：中文系统显示中文，其余显示英文。
- 设置 → 常规 → 语言 可改为跟随系统、中文或 English，立即生效。托盘菜单的文字在下次启动后更新。
- 选择保存在数据目录的 `language` 文件，内容为 `system`、`zh` 或 `en`。
- 两个安装程序（NSIS 与 Inno Setup）在安装时把所选安装语言写入 `%APPDATA%\AirPlay Hub\language`，应用首次启动即按该语言显示。

未翻译的部分：`airplay-desktop` 和后端返回的错误信息、逐包诊断摘要行、日志目录的显示路径。它们由服务层生成，目前只有中文。

## 布局

- 顶栏即标题栏：系统标题栏已隐藏，整块可拖动；外观、设置和最小化 / 最大化 / 关闭按钮在窗口右上角。设置页显示返回按钮、版本号和 常规 / 运行统计 / 技术详情 / 日志 标签。
- 播放页两个分组：音频来源（采集开关、L/R 电平与总峰值、来源告警；格式参数在 设置 → 技术详情）、AirPlay 设备（刷新，可展开）。
- 设备卡片展开：连接后显示左右扬声器、各自电平和交换位置；未连接时显示成员地址与端口。
- 底部固定栏：左右两区等宽，音量条本身居中（右侧留出与静音图标等宽的空位）。音量百分比在悬停 1 秒后以提示显示。
- 密码输入固定在底部栏上方。错误以可关闭的横幅显示在内容顶部。
- 缩放：内容列最宽 960px，窗口更宽时居中；窗口最小 720x560。
- 动效：设备展开 / 收起、换页、密码框和错误提示有过渡；滚到顶或底继续拨动会弹性拉出再回弹。系统开启“减少动画”时全部关闭。

## 视觉规则

- 网格：8px 基准；页面外边距 32，组间 24，组标题与卡片 8，卡片内边距 16。
- 分组：标题在卡片外，小号、次要色，左缘与卡片内文字对齐；内容在带背景的卡片里，行间用细线分隔。
- 卡片内容到四边都是 16；行与行之间是 8、细线、8。
- 圆角：控件、设备卡片、电平块、日志框为 6；卡片、指标卡与密码浮层为 12。
- 数据行：名称在左，数值贴右；设置行同样是名称在左、控件在右。
- 视觉对齐：幽灵按钮向外偏移 8px，让图标或文字本身贴齐内容边线；大号数字的单位落在数字基线上。
- 等宽数字：根节点开启 `tnum`，电平、音量、时长、计数跳动时不抖动。

## 与 src-gpui 的行为差异

- 首次发现设备后默认选中第一张卡片（立体声对在前），不需要手动点选。
- 播放提前量和 Buffer 用数字输入框，回车、失焦或点步进时保存，没有单独的“保存”按钮。
- 标题栏的外观按钮直接把外观设置保存为浅色或深色。
- 会话报告在界面中最多显示前 400 行；“复制报告”仍复制完整内容。

## 依赖说明

Ely 依赖 `gpui-pre 0.3.11`，与 `src-gpui` 的 `gpui 0.2.2` + `gpui-component 0.5.1` 类型不兼容，所以是独立 crate。Ely 目前标注为 early，尚无稳定的 crate；依赖固定在提交 `69a62b1`。
